# golden-bull-school

Golden Bull School｜金牛学派，商业公理、短视频文稿开源库

## 目录结构

| 目录 | 内容 |
| --- | --- |
| `00 Preface 总序` | 学派宣言、版本更新日志、核心术语规范 |
| `01 ANL (Artigence Native Language) 硅基母语` | ANL 的定义、语法范式、通信原理、应用场景 |
| `02 Dual-Brain Paradigm 双脑范式` | 核心公理、人硅分工模型、协同工作流、边界约束 |
| `03 Immortality Boundary 永生边界` | 核心命题、意识留存理论、伦理框架、技术路径、安全约束 |
| `04 Public Theory 公开基础理论` | 致富科学论、金牛资产哲学（公开版） |
| `05 Open Toolkit 开源工具集` | MCP 搭建手册、ANL 提示词库、提交规范 |
| `99 Global Drafts 全球公开初稿区` | 未定稿草稿，不作为引用依据 |

## 阅读顺序

先读 `00 总序` 立口径，再读 `01 ANL` 与 `02 双脑范式` 打地基；`03 永生边界` 是长期命题；`04` `05` 是对外可直接使用的部分。
