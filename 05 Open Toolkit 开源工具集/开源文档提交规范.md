# 开源文档提交规范

> 目的：多人写、多年改，结构不能散。

## 一、目录与命名

- 一级目录固定为 `00`–`05` 与 `99`，编号含义不换位
- 文件名用「主题.md」，不加日期、不加版本号（版本靠 git 管理）
- 禁止在文件名中使用 `\ / : * ? " < > |`

## 二、文件骨架

```markdown
---
status: 待撰写 | 可用 | 已废弃
updated: YYYY-MM-DD
---

# 标题

> 一句话定位：

## 正文
```

- 废弃不删文件，改 `status: 已废弃` 并保留原因
- 一个文件只讲一件事，超过 3000 字考虑拆篇

## 三、提交信息格式

```
类型(范围): 简述

新增 | 修订 | 修正 | 重构
示例：修订(02 双脑范式): 补充人硅分工决策树
```

## 四、审校流程

1. 自校：结构完整、无占位符残留
2. 交叉校：至少一人通读，重点查术语是否与《核心术语规范》一致
3. 登记：在《版本更新日志》补一行
4. 合并：主分支只接受 PR，不直接 push（维护者除外）

## 五、引用与出处

- 引用外部观点必须给出处（作者 / 链接 / 日期）
- 数据必须标注口径与时间，否则不得作为论据
